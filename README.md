# 活动出勤登记

一个纯前端、无需安装、打开即用的出勤登记工具。数据保存在本机浏览器的 localStorage 中。

## 使用方式

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge / Firefox 最新版）。

## 功能说明

### 1. 成员管理
- 添加 / 删除成员；删除成员会同时清除其全部出勤记录（有记录时会二次确认）。
- 成员重名时会提示。
- **小组管理**：添加 / 删除小组，添加成员时可直接选择所属小组，成员列表中也可随时调整；删除小组后其成员自动变为「未分组」（出勤记录不受影响）。

### 2. 出勤登记
- 新建活动：填写活动名称与日期（默认当天），由负责人在活动当天登记。
- **活动排班**：活动建好后可提前为每位成员预排**分工**、指定**负责人**；未排满时排班面板会醒目提醒（含未排班成员名单、未指定负责人提醒），未排班的行以橙色占位标注。
- 登记出勤时**自动带入**排好的分工与负责人标记（含「全部到场」批量操作），现场仍可修改——修改只影响本次登记，不改动排班；先登记后补排班时，已到场且分工为空的记录会自动回填。
- 排班随活动保存（localStorage），删除活动时一并清除；删除成员时其排班也一并移除。
- 逐人标记「到场 / 缺席」，到场成员可填写：
  - **参与时长**（小时，按 0.5 小时为步长登记，输入 1.25 这类数值会自动取整到最近的 0.5；单次上限 24 小时，超出时会即时提示并按上限记录）
  - **承担分工**（如主持、摄影、物资；已填写过的分工可从下拉建议中快速选择）
- 直接填写时长或分工会自动标记为到场；标记缺席时时长与分工自动清空。
- 设有小组后，登记页可**按小组筛选**成员；此时「全部到场 / 全部缺席 / 清除登记」只作用于当前小组，底部统计也按当前小组显示。
- 支持「全部到场 / 全部缺席 / 清除登记」批量操作。
- 所有更改自动保存，底部实时显示已登记人数、到场、缺席、总时长。
- 活动列表按日期倒序排列，可随时切换历史活动补录或修改；删除活动会连带删除该活动的登记记录。

### 3. 成员汇总
- **小组汇总**：分开统计各小组（含未分组）的成员数、参与次数、缺席次数与累计参与时长。
- 按成员汇总：**参与次数**（到场次数）、**累计参与时长**、承担过的**分工及次数**标签（含「负责人」次数），并显示缺席次数与所属小组。
- 按参与次数从高到低排序。
- 点击任意成员可展开其**历次参与记录**（日期、活动、到场/缺席、时长、分工）。

## 数据说明

- 数据仅存储在当前浏览器的 localStorage（键名 `attendance-app-data-v1`），不会上传到任何服务器。
- 清除浏览器数据、换浏览器或换电脑都会导致记录无法看到，重要数据请定期保留同一浏览器环境使用。
